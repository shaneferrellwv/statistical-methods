EN.605.631 — Chapter 5 Assignment Hints (Continuous Random Variables)

Use these hints to structure your work and sanity‑check results. Keep derivations in your notebook; these notes aim to guide, not replace, your proofs/calculations.

Quick roadmap

  • Name the random variable X and its support (interval(s) on ℝ).
  • Decide whether to work with pdf f(x) or cdf F(x). Use F(b)−F(a) for interval probabilities.
  • Verify pdf properties: f(x) ≥ 0 on the support; ∫ f(x) dx = 1.
  • For expectations, default to LOTUS: E[g(X)] = ∫ g(x) f(x) dx.
  • If a known family (Normal, Exponential, Gamma, Weibull) fits, reuse its facts (means, variances, cdf conventions).
  • Plot pdf (smooth curve) and cdf (smooth, increasing, horizontal tails). Check qualitative shape (e.g., skew).

Problem 1 — PDF, CDF, and Probability (22 pts)

  • Start by writing support S and check that ∫_S f(x) dx = 1. If not, renormalize or re‑check limits.
  • Connection: F(x) = ∫_{-∞}^x f(t) dt; if F is given, recover f by differentiating on points of continuity.
  • Compute sample probabilities via cdf differences: P(a < X ≤ b) = F(b)−F(a). For continuous X, points have prob 0.
  • Always include units/interpretation (e.g., seconds, meters) and a quick sketch of f and F.

Problem 2 — LOTUS & Transformations (22 pts)

  • LOTUS first: for any function g, compute E[g(X)] = ∫ g(x) f(x) dx on the support.
  • If Y = g(X) and g is monotone, use the change‑of‑variables formula: f_Y(y) = f_X(g^{-1}(y)) |d/dy g^{-1}(y)|.
  • If g is not monotone, partition the preimage: sum contributions from each branch x_i(y) where g(x_i)=y.
  • For linear transforms: E[aX+b]=aE[X]+b, Var(aX+b)=a^2 Var(X)—use these before integrating from scratch.

Problem 3 — Normal Distribution (22 pts)

  • Standardize: if X ~ N(μ, σ^2), set Z=(X−μ)/σ ~ N(0,1); use pnorm, qnorm to evaluate probabilities/quantiles.
  • Symmetry: P(X ≥ μ) = 0.5, and P(|X−μ| ≤ kσ) matches the 68–95–99.7 rule (approx).
  • Linear combos: sums of independent normals are normal; aX+b remains normal with mean aμ+b, var a^2σ^2.
  • When sketching, indicate μ and μ±σ on the horizontal axis for orientation.

Problem 4 — Normal Approximation (22 pts)

  • Binomial → Normal: if X ~ Bin(n,p) with np(1−p) not tiny, use N(μ=np, σ=√(np(1−p))).
  • Apply continuity correction: turn P(X ≤ k) into P(Y ≤ k + 0.5) where Y is the normal approximation.
  • Sanity checks: tail probs should be in [0,1]; P(X in plausible range) ≈ 1; compare to exact pbinom for a few values.

Problem 5 — Exponential Distribution (EC)

  • X ~ Exp(λ) has f(x)=λ e^{−λx} for x≥0, E[X]=1/λ, memoryless: P(X>s+t | X>s)=P(X>t).
  • For minimum of exponentials: if independent with rates λ_i, then min(X_i) ~ Exp(Σ λ_i); P(argmin = i) = λ_i / Σ λ_j.
  • Convert between rate and scale if needed (scale = 1/λ). Be consistent throughout the problem.

Problem 6 — Gamma Distribution (EC)

  • X ~ Gamma(α, λ) (shape α>0, rate λ>0) has mean α/λ, variance α/λ^2. For integer α=r, it’s Erlang (sum of r exponentials).
  • Use the incomplete gamma (or pgamma) for cdf calculations; don’t try to integrate by parts repeatedly unless asked.
  • If a Poisson‑process interpretation appears, recognize waiting time to the r‑th event → Gamma(r, λ).

Problem 7 — Weibull Distribution (EC)

  • Weibull(shape k, scale η): F(x)=1−exp{−(x/η)^k} for x≥0; E[X]=η Γ(1+1/k).
  • Hazard behavior: increasing if k>1, constant if k=1 (exponential), decreasing if k<1.
  • Useful transform: if T ~ Weibull(k, η), then (T/η)^k ~ Exp(1)—handy for simulation and proofs.

Problem 8 — Distribution of a Function (EC)

  • For Y=g(X) with a non‑monotone g (e.g., g(x)=x^2), split the support into monotone pieces and sum Jacobian terms.
  • Prefer the cdf method when algebra gets messy: compute P(Y ≤ y) = P(g(X) ≤ y) first, then differentiate to get f_Y.
  • Check support carefully: list all y values that can occur and justify endpoints.

Common pitfalls

  • Forgetting to specify support or using wrong limits of integration.
  • Dropping absolute values in the Jacobian for transformations.
  • Skipping the continuity correction in normal approximations to discrete distributions.
  • Confusing rate (λ) with scale (1/λ); mixing parameterizations within a problem.
  • Plotting a continuous cdf with jumps (it should be continuous and nondecreasing).
  • Not checking that ∫ f(x) dx = 1 before proceeding.
