Problem 2 — Permutations (with/without indistinguishables)

  • §1.3 Permutations (pp. 3–5)
  • Indistinguishable items (Example 3d)

Strategy hints:

  • When order matters and all items are distinct, start with n!.
  • If there are repeated types, divide by the factorial of each multiplicity.
  • For 'blocks stay together', permute blocks, then permute within blocks.

Starter R code:

# Starter: Permutations and factorial
n <- 10
total_perm <- factorial(n)
# With indistinguishables: n!/(n1!*n2!*...)
n1 <- 4; n2 <- 3; n3 <- 2; n4 <- 1
perms_indist <- factorial(10) / (factorial(n1)*factorial(n2)*factorial(n3)*factorial(n4))
c(total_perm, perms_indist)

Problem 3 — Combinations & Identities

  • §1.4 Combinations (pp. 5–8)
  • Identity (4.1)

Strategy hints:

  • When order does not matter, use choose(n, r).
  • For multi-category committees, multiply independent choose() counts across categories.
  • Watch out for exclusions (e.g., two people who cannot serve together): subtract those cases.

Starter R code:

# Starter: Combinations
n <- 20; r <- 3
choose(n, r)  # number of r-combinations from n
# With groups, multiply choose() results across independent selections
choose(5, 2) * choose(7, 3)

Problem 4 — Binomial Theorem: Algebra, Code, and Coefficients

  • §1.4 Binomial Theorem (eq. 4.2, pp. 7–8)
  • Examples 4d–4e

Strategy hints:

  • Recall (x + y)^n = sum_{k=0}^n choose(n,k) x^k y^{n-k}.
  • To verify identities numerically, pick concrete x, y and compare both sides.
  • Coefficients follow Pascal’s rule (Identity 4.1).

Starter R code:

# Starter: Binomial coefficients and theorem
n <- 6
k <- 0:n
coeffs <- choose(n, k)
coeffs
# Expand (x + y)^n symbolically? Use numeric check:
x <- 2; y <- 3
sum(coeffs * x^k * y^(n-k))

Problem 5 — Multinomial Coefficients & Theorem

  • §1.5 Multinomial Coefficients (pp. 9–11)
  • Multinomial Theorem

Strategy hints:

  • Partitioning n distinct items into labeled groups of sizes n1,...,nr uses n!/(n1!...nr!).
  • Relate to permutations with indistinguishable labels to build intuition.
  • Check edge cases: some ni can be zero; the formula still applies.

Starter R code:

# Starter: Multinomial coefficient
n1 <- 5; n2 <- 2; n3 <- 3
n <- n1 + n2 + n3
multinom_coeff <- factorial(n) / (factorial(n1)*factorial(n2)*factorial(n3))
multinom_coeff

Problem 6 — Stars and Bars (Integer Solutions)

  • §1.6 Number of Integer Solutions (pp. 12–15)
  • Stars-and-bars (Prop. 6.1–6.2)

Strategy hints:

  • Nonnegative integer solutions of x1+...+xr = n count is choose(n+r-1, r-1).
  • Positive solutions: shift by 1 or use choose(n-1, r-1).
  • Translate 'at least k between items' into shifted constraints.

Starter R code:

# Starter: Stars and Bars (nonnegative integer solutions)
# Number of solutions to x1 + ... + xr = n is choose(n + r - 1, r - 1)
n <- 20; r <- 4
choose(n + r - 1, r - 1)
# Positive solutions: choose(n - 1, r - 1)
choose(n - 1, r - 1)
