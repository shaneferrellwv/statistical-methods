EN.605.631 — Chapter 8 Assignment Hints (Limit Theorems & Approximations)

Use these hints to decide which tool fits each question—inequalities (Markov/Chebyshev/Cantelli), LLN/CLT, Chernoff, or Poisson approximation—and to sanity-check answers.

Quick roadmap

  • Markov/Chebyshev/Cantelli are worst-case, moment-only bounds. Use when distributional info is scarce.
  • WLLN/SLLN control how the sample mean behaves as n grows (in probability vs almost surely).
  • CLT gives an approximate distribution for standardized sums/means; add continuity correction for discrete counts.
  • Chernoff (mgf/KL) gives exponential tail bounds for sums of independent RVs, usually sharper than Chebyshev.
  • Poisson approximation is for rare-event counts ("law of small numbers"): Binomial/independent indicators → Poisson(λ≈np).
  • Always: state assumptions (independence, identical distribution, finite variance, mgf existence) before applying a theorem.

Problem 1 — Markov, Chebyshev, One-Sided Chebyshev (10 pts)

  • Markov (nonnegative X): P(X ≥ a) ≤ E[X]/a. Use when only E[X] is known.
  • Chebyshev: P(|X−μ| ≥ t) ≤ Var(X)/t^2. Great for centering around the mean; needs finite variance.
  • One-sided Chebyshev (Cantelli): P(X−μ ≥ t) ≤ σ^2/(σ^2 + t^2) and similarly for the left tail.
  • Decide which bound fits the query (two-sided vs one-sided) and plug in μ, σ^2, t. Report the tightest among applicable bounds.

Problem 2 — WLLN by Chebyshev (10 pts)

  • For i.i.d. with mean μ and variance σ^2<∞, show Var(\bar X_n)=σ^2/n.
  • Apply Chebyshev to the sample mean: P(|\bar X_n − μ| ≥ ε) ≤ σ^2/(n ε^2).
  • State: as n→∞, RHS→0 ⇒ \bar X_n → μ in probability (WLLN). Optionally show a small simulation path.

Problem 3 — CLT (accuracy & continuity) (14 pts)

  • Standardize: Z = (S_n − nμ)/(σ√n) or Z = (\bar X_n − μ)/(σ/√n); then Z ≈ N(0,1) by CLT.
  • Continuity correction for discrete S_n (e.g., Binomial/Poisson):
    • P(S_n ≤ k) ≈ Φ((k+0.5 − nμ)/(σ√n)), P(S_n ≥ k) ≈ 1 − Φ((k−0.5 − nμ)/(σ√n)).
  • Accuracy: mention Berry–Esseen idea — error ≈ O(1/√n) when a finite third absolute moment exists. Use this to justify n-requirements qualitatively.

Problem 4 — Choose n: CLT vs Chebyshev (12 pts)

  • Goal: choose n for P(|\bar X_n − μ| ≤ ε) ≥ 1 − δ.
  • Chebyshev route: ensure σ^2/(n ε^2) ≤ δ ⇒ n ≥ σ^2/(δ ε^2) (simple, conservative).
  • CLT route (two-sided): require P(|Z| ≤ z_{1−δ/2}) ≈ 1 − δ ⇒ ε ≥ z_{1−δ/2} σ/√n ⇒ n ≥ (z_{1−δ/2} σ/ε)^2.
  • Compare the n from both methods; comment on which is more realistic for the given distribution/n scale.

Problem 5 — Chernoff vs Chebyshev/Exact (12 pts)

  • For a sum of independent RVs, Chernoff bound: P(S_n ≥ a) ≤ inf_{t>0} e^{−ta} M_{S_n}(t) where M_{S_n}(t)=∏ M_X(t).
  • For Bernoulli/Binomial: use KL form P(S_n ≥ nq) ≤ exp(−n D(q || p)) with D(q||p)=q log(q/p)+(1−q)log((1−q)/(1−p)).
  • Compare numerically with Chebyshev and, if feasible, with the exact binomial tail (or normal approx + continuity).
  • Comment on regimes: Chernoff much tighter in the large-deviation (far-tail) regime; Chebyshev is coarse but moment-based.

Problem 6 — SLLN Visualization (10 pts)

  • Visualize SLLN: plot \bar X_n vs n for one or many simulated paths with horizontal line at μ.
  • Overlay a √n-scaled band if helpful: μ ± c σ/√n to emphasize shrinking variability (not a.s. proof but useful intuition).
  • Use distributions with and without finite variance to contrast behavior (e.g., compare Exp(1) vs a heavy-tailed Pareto).

Problem 7 — Poisson Approximation (14 pts)

  • Use Poisson(λ=np) to approximate Bin(n,p) when n is large and p is small (keep λ moderate).
  • Compute exact Bin(n,p) probabilities for a few events and compare with Pois(λ); comment on relative error.
  • Rule-of-thumb: good when p ≤ 0.05 and n ≥ 100. A theoretical guardrail: Le Cam gives total variation ≤ 2 n p^2 for Binomial.
  • If events are independent but not identical (different p_i), use λ=∑ p_i and the same idea.

Problem 8 — CLT in Practice (18 pts)

  • Lay out the data-generating story: identify μ, σ^2, independence assumptions, and whether counts are discrete.
  • Choose between CLT (normal approximation with/without continuity correction), Chernoff (upper/lower tail bounds), or Poisson approx for rare events.
  • Provide a brief diagnostic: np or λ scale, skewness, and sample size to justify your chosen approximation.
  • Validate with a quick simulation for at least one parameter setting and report the observed vs predicted probability.

Common pitfalls

  • Applying CLT at very small n without checking symmetry/skew or using continuity correction for discrete sums.
  • Forgetting assumptions (i.i.d., finite variance, mgf existence) before invoking LLN/CLT/Chernoff.
  • Mixing up one-sided vs two-sided bounds (use Cantelli for one-sided).
  • Using Poisson approximation when p is not small or np is large (the tail may be very inaccurate).
  • Comparing bounds to exact probabilities without noting that bounds are not equalities—they can be loose.
